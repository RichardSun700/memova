# Action ecosystem icons

Brand marks are used only to identify illustrative current or planned destinations in the Memova homepage prototype.

- Gmail, Google Calendar, Notion, and GitHub paths come from the Simple Icons `develop` branch.
- Microsoft Outlook comes from Simple Icons `12.4.0`.
- OpenAI and Slack come from Simple Icons `15.16.0`.
- Social platform marks reuse the existing files in `../social/`.

Simple Icons is CC0, but the represented brand marks remain the property of their respective owners. Showing a mark does not imply endorsement or that an integration is currently available; the website copy must keep availability and permission boundaries explicit.
